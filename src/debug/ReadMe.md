# Debug helpers

The eight debug helpers and HRESULT lookup forms use Lazarus LCL. See [the tooling guide](../../tools/ReadMe.md) and [the LCL project](../../tools/WinHResultTools.lpi). Core SDK units remain GUI-free.

The original Delphi tree keeps VCL. Current validation and limits are in [DEBUG_TOOLS_PORTING.md](../../docs/DEBUG_TOOLS_PORTING.md).
